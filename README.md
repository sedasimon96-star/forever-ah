# forever-ah

Personal market analytics and profit planning tool for WoW Forever (EU).

- Auction house price analysis (current listings and price history by hour and weekday)
- Crafting profit planning across professions: material cost, sale price, estimated sales per day, real profit per day
- Make-vs-buy decisions for reagents and pattern ROI

This is a private tool. Its source code and data live in a private repository and its reports are not published.
This repository only describes the project and credits the data sources.

## Data sources and credits

- Reference data (professions, recipes, skill levels, pattern sources, vendors, items):
  [Data from ForeverDB.net](https://foreverdb.net)
- Auction house listings and static game data: [Blizzard Battle.net Game Data API](https://develop.battle.net/documentation/world-of-warcraft-classic)
